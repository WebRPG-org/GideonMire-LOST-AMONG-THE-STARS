Lost Among The Stars – RPG Game
A space-themed adventure game featuring a deep, story-driven 2D RPG experience with 5 levels, player interactivity, in-game currency, and dynamically scripted events.

🎮 Game Overview
In Lost Among The Stars, you navigate a vast cosmic landscape, exploring alien worlds and uncovering secrets. With five engaging levels and an immersive storyline, the game places you at the heart of a galactic conflict where your decisions matter. The game features:
A narrative-driven RPG arc set in space
Five distinct levels with increasing challenges
Full player control of character movement, quests & interactivity
An in-game currency system to upgrade gear or access special areas
Dynamic event scripting — game world responds to your actions

Technical Features & Implementation
Developed in 2D with emphasis on story and exploration
Player interactivity: NPC dialogues, branching choices, inventory use
In-game currency to unlock upgrades/abilities
Conditional logic events (e.g., unlocking secret level only if criteria met)
Structured level progression with increasing difficulty
